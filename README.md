# 🛍️ Customer Shopping Behavior Analysis — SQL, Python & Power BI

An end-to-end data analytics portfolio project that explores customer shopping trends using **SQL** for data querying, **Python** for exploratory data analysis, and **Power BI** for interactive dashboarding — mirroring a real-world analyst workflow from raw data to business insight.

---

## 📌 Project Overview

This project analyzes customer shopping behavior to uncover patterns in purchasing habits, demographics, and spending trends. The goal is to help a business understand **who its customers are**, **what drives their purchases**, and **where opportunities for growth exist**.

The workflow covers the full analytics lifecycle:
1. **Data Cleaning & Preparation**
2. **SQL-based Querying & Aggregation**
3. **Exploratory Data Analysis (Python)**
4. **Interactive Dashboard (Power BI)**
5. **Business Reporting & Insights**

---

## 🧰 Tools & Technologies

| Tool | Purpose |
|------|---------|
| **SQL** | Data querying, aggregation, and business logic |
| **Python (Pandas, Matplotlib/Seaborn)** | Data cleaning, EDA, and visualization |
| **Power BI** | Interactive dashboard and reporting |
| **Jupyter Notebook** | Analysis walkthrough |

## 📁 Repository Structure

| File | Description |
|------|-------------|
| `Business Problem Document.pdf` | Defines the business problem, objectives, and scope |
| `customer_shopping_behavior.csv` | Raw dataset used for analysis |
| `customer_behavior_sql_queries.sql` | SQL scripts used to query and analyze the dataset |
| `Customer_Shopping_Behavior_Analysis.ipynb` | Python notebook with EDA and visualizations |
| `customer_behavior_dashboard.pbix` | Power BI interactive dashboard |
| `Customer Shopping Behavior Analysis.pdf` | Final written analysis report |
| `Customer-Shopping-Behavior-Analysis.pptx` | Presentation summarizing key findings |

---

## 🔍 Key Analysis Areas

- Customer demographics and segmentation
- Purchase frequency and spending patterns
- Category-wise and seasonal shopping trends
- Payment method and discount usage trends
- Customer retention and repeat purchase behavior
